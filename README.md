# Fresh Grocers — Online Grocery Landing Page

Live Demo: https://freshgrocers-landing.netlify.app  
Source Code: https://github.com/ShavishaThiloshini/fresh-grocers-landing-page

---

## Project Overview

Fresh Grocers is a **modern, responsive online grocery landing page** designed and developed using **HTML, CSS, and AOS animations**.  
This page showcases a clear and eye-catching UI, with product highlights, call-to-action sections, and seamless layout transitions. It’s fully responsive and suitable for converting visitors into customers.

---

## Features

- Clean and modern UI design  
- Fully responsive across devices  
- Product showcase section  
- Quick order call-to-action  
- AOS scroll animations  
- Hero banner with image  
- Animations & hover effects  
- Live demo hosted with Netlify
